# python-whatsnew-digest

Handout digest covering what changed in the official Python 3.13 "What's New" release notes.

This repository documents the changes in Python 3.13 through a reviewed pull request rather than dumping straight onto the default branch.

## What this repository is for

A handout digest of the official Python 3.13 release notes, as reviewed through a pull request. The full digest including highlights, deprecations, and the source page is in `python-313-digest.md` on the `python-313-digest` branch.

## Source

Official "What's New in Python 3.13" release notes: https://docs.python.org/3/whatsnew/3.13.html
