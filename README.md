# python-whatsnew-digest

Handout digest covering what changed in the official Python 3.13 "What's New" release notes, created as a reviewed pull request rather than dumped straight onto the default branch.

## What this repository is for

A handout digest of the official Python 3.13 release notes, reviewed through a pull request on the `python-313-digest` branch. The full digest including highlights, deprecations, and the source page is in `python-313-digest.md`.

## Source page

Official "What's New in Python 3.13" release notes: https://docs.python.org/3/whatsnew/3.13.html
