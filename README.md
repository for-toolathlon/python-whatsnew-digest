# python-whatsnew-digest

Handout digest covering what changed in the official Python 3.13 "What's New" release notes.

This repository is for the Python 3.13 digest handout. It is built using the official Python 3.13 release notes reviewed through a pull request. The full digest, including highlights, notable deprecations, and the source page, is in the file `python-313-digest.md` on the `python-313-digest` branch.

### Source

Official "What's New in Python 3.13" release notes: https://docs.python.org/3/whatsnew/3.13.html
